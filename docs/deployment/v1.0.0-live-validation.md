## Deployment Fixes Applied

### Infrastructure (Bicep)
- **Storage naming:** `take(projectName, 4)` + `take(uniqueString(...), 10)` to fit 24-char limit
- **Service Bus:** Renamed from `-sb` (reserved suffix) to `-bus`
- **Key Vault:** Added `uniqueString` suffix to avoid soft-delete name conflicts
- **Region:** Changed from `eastus` to `eastus2` (eastus had Cosmos DB + Functions issues)
- **Functions plan:** Switched from FC1 (FlexConsumption) to B1 (Basic) — but still blocked by quota
- **Search:** Switched from standard to free tier — but eastus2 capacity exhausted
- **Functions/RBAC modules:** Commented out in main.bicep with re-enable instructions

### Backend (Python)
- **ClaimRecord model:** Added `id` and `policyId` fields for Cosmos DB compatibility
- **ClaimStateStore:** Changed `get_claim()` from `read_item()` to cross-partition `query_items()`
- **Tests:** Updated mock from `read_item` to `query_items`

## Re-enabling Functions + Search + RBAC

1. Request App Service quota: Azure Portal > Subscriptions > {sub} > Usage + quotas > Request increase
2. Search for "App Service" and request at least 1 Dynamic or Basic VM
3. Uncomment Functions, Search, and RBAC modules in `infra/main.bicep`
4. Re-run: `az deployment sub create --location eastus2 --template-file infra/main.bicep --parameters infra/parameters/dev.bicepparam`
